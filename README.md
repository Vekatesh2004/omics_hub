# OmicsHub Recruiter — Complete Frontend

React + Vite frontend for a scientific recruitment platform.

## Included
- Professional recruiter sign-in and registration
- Email/password frontend authentication with localStorage
- Google authentication UI placeholder ready for Firebase/OAuth integration
- Dashboard with populated demo recruitment data
- Active jobs, applications, shortlisted, interviews and hired metrics
- Recruitment funnel
- Job management, posting, edit, details, close/reopen and delete
- Candidates
- Applications
- Shortlisted candidates
- Interviews
- Assessments
- Talent Search
- Saved Candidates
- Messages
- Analytics
- Notifications
- Company Profile
- Settings
- Billing
- Responsive design
- Browser back/forward navigation
- Existing `src/recruiter/utilis/storage.js` naming preserved

## Run

```bash
npm install
npm run dev
```

The Google button is intentionally a UI integration point. For real Google authentication, connect Firebase Authentication or another OAuth provider.
