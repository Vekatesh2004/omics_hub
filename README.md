# Omics Hub – Advanced Plan

## Overview

**Omics Hub – Advanced Plan** is a web-based career and skill-development platform prototype designed to help users explore job opportunities, identify skill gaps, track training progress, and manage career development in the life sciences and bioinformatics fields.

The platform provides a dashboard that brings career-related information and learning activities together in one place.

## Features

- **Dashboard:** View career statistics, skill information, and learning progress.
- **Resume Upload:** Upload a resume and experience a simulated resume-evaluation workflow.
- **Skill Gap Analysis:** Identify skills that may need improvement for career goals.
- **Job Opportunities:** Browse sample job listings and use filters to explore relevant roles.
- **Training Progress:** Track sample learning activities and course completion.
- **Plan Management:** View available platform plans and interact with plan-selection features.
- **Notifications:** View interface notifications and updates.
- **Interactive Interface:** Navigate through the dashboard using the sidebar, buttons, filters, and modal windows.

## Getting Started

### Run Locally

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a modern web browser.
4. Explore the dashboard and its interactive features.

No additional installation is required for the basic front-end prototype.

## Deployment Using GitHub Pages

1. Open the repository on GitHub.
2. Navigate to **Settings**.
3. Select **Pages** from the sidebar.
4. Under the build and deployment settings, select **Deploy from a branch**.
5. Select the `main` branch and the root folder (`/`).
6. Click **Save**.
7. Wait for GitHub Pages to publish the website, then open the generated URL.

## Current Limitations

This project is a front-end prototype. Some features are demonstrations rather than fully connected services.

- Login functionality is demonstrative and does not provide production-ready authentication.
- Resume evaluation and skill-gap analysis use simulated front-end behavior.
- Job listings contain sample data and are not verified live vacancies.
- Training progress is not connected to a persistent database.
- Plan selection does not process real payments.
- No production backend or database is connected.
